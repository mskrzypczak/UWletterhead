UWletterhead

UWletterhead is a LaTeX class package that enables to create official PDF documents for the Faculty of Mathematics, Informatics and Mechanics of the University of Warsaw. The package is based on the official Identification Codebook of the University of Warsaw and on the official logo of the Faculty.

Quick Start Guide

  • download the package and unpack it
  • go to the directory UWletterhead
  • build test.tex using pdflatex twice (execute pdflatex test.tex two times): the logos, the footer and the page numbers are positioned relatively to the page and are in place only after the second run
  • open the new file test.pdf

The package needs the files UWletterhead.cls, UWlogoPL.pdf, UWlogoEN.pdf and MIMlogo.pdf, and for the option arimo also Arimo-Regular.ttf, Arimo-Regular.tfm, Arimo-Bold.ttf, Arimo-Bold.tfm, T1Arimo.fd and T1-WGL4.enc, to be put in the current directory of your *.tex file!

For more information, see the manual.

Layout issues

Function & name font

There is a conflict between Identification Codebook and the examples given at the website of Identification Code (the page with the examples of the Faculty is protected with a password).

The codebook (page 16) defines that:

  • the function of a person should be given in bold, black
  • the title, name, and surname should be given in regular font, black.

The examples use regular font, gray for both. Sometimes the function and the rest is put in one line, sometimes in separate lines. The example of a letterhead in the codebook itself (page 18) uses the opposite weights: the function in regular font, gray, and the name in bold, gray.

The current version of the template follows Identification Codebook (page 16), except for the color that is gray not black.

Address footer position

Identification Codebook specifies that the address footer should be aligned left and positioned 56 mm from the left border of the page. The examples violate this, the distance is 53.5 mm instead of 56 mm.

The current version of the template follows Identification Codebook.

Logo of the Faculty in English documents

In the English template of January 2020 (Wydzial_EN_2.pdf) the bar and the logo of the Faculty are 6 mm closer to the logo of the University than in the Polish one (Wydzial_PL_2.pdf).

The current version of the template puts them as in the Polish template, also with the option english.

Margins and padding

Identification Codebook does not specify the general margins of the documents nor spacing between the elements (e.g. the header and the body text). These values are chosen arbitrarily and can be modified by the user (see \geometry and \UWheadsep macros).

Arimo font

Identification Codebook specifies that the font used for all the elements of the document should be Arimo. The class comes with this font, but its metrics (Arimo-Regular.tfm, Arimo-Bold.tfm) have no kerning and no ligatures, so --, ---, ,,, '', << and >> are not converted into dashes, quotation marks and guillemets, and there is no italic shape: LaTeX substitutes the upright shape, with a font warning. Every letter of the T1 encoding is printed except \SS; before the correction of T1-WGL4.enc on 27.11.2026, also Ż and ż were missing.

The current version of the template allows to use Arimo font by including option arimo in the \documentclass[]{UWletterhead} arguments. However the default font for UWletterhead is Droid, which is similar to Arimo but different.

Verification

It is possible to verify the relative alignment of the elements in the document in comparison to the examples presented at the webpage of Identification Code. These examples (transformed to PDF) are available as templates/<name>.pdf on this site, for instance templates/I-Informatyki_PL.pdf. You can also download all of them in an archive: templates.zip or templates.tar.gz.

To use one of those examples, you can include \renewcommand{\UWoverlap}{path-to-a-given-file} in the preamble, for instance:

\documentclass[polski,arimo]{UWletterhead}

\renewcommand{\UWinstitute}{Instytut Informatyki}

\renewcommand{\UWaddress}{ul.}
\renewcommand{\UWphone}{tel}
\renewcommand{\UWemail}{\ }

\renewcommand{\UWoverlap}{templates/I-Informatyki_PL.pdf}

\begin{document}
\UWheader


\end{document}

There are certain discrepancies, as discussed above. Moreover, the class places the lines with the unit names as in the templates of January 2020 (MIM_logo.pdf, Wydzial_PL_2.pdf, Wydzial_EN_2.pdf); in the older templates of February 2017 they are 3 mm higher.

Measurement

An external way is to use Adobe Acrobat Reader (or other tool) to measure the relative positions of the elements of the layout. For instance Adobe Acrobat provides a tool called Measuring tool under Edit ≫ Analysis menu.
